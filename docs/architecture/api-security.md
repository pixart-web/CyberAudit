# API Security

OpenAPI 2.0, 3.0 and 3.1 JSON documents can be uploaded to private storage,
previewed and explicitly confirmed. Paths are normalized, operations inventoried
and authentication declarations recorded. External, absolute, file and traversal
references are rejected and no remote reference is resolved.

Runtime checks remain behind jobs and the central network policy. Phase 5 does
not submit forms, mutate resources, fuzz parameters, brute-force identities or
use production credentials. Contract analysis is offline.
