# Inventário técnico

`cyberaudit.asset_inventory` consolida apenas dados da plataforma e fontes selecionadas numa enum. Pode resolver o hostname exato quando a fonte DNS está ativa, mas não percorre redes, intervalos, vizinhos ou novos alvos. Observações atualizam `last_seen_at`; novos ativos e mudanças materiais são sugestões sujeitas a revisão.
