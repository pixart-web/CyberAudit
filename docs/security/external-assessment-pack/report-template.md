# Independent assessment report template

Record assessor identity/company, authorization reference, environment, commit,
application version, dates, tools/versions and exact scope. For every test,
record result, sanitized evidence reference and limitations. For every finding,
record severity, confidence, affected component, reproduction within the
authorized environment, impact and remediation.

The final section must state unresolved HIGH/CRITICAL findings, retest status,
assessment limitations and the report SHA-256. An internal human reviewer must
separately approve the checksum; self-attestation by automation is invalid.
